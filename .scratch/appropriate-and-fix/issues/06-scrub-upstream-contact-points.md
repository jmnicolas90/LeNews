# 06 — Scrub every upstream contact, funding and store surface

Type: task
Status: resolved
Blocked by: 05

## Question

Upstream's README carries Play Store, F-Droid and PayPal badges and a Weblate badge; `.github/FUNDING.yml` names upstream's funding; `.github/ISSUE_TEMPLATE/` may carry upstream links; `fastlane/metadata/` is upstream's store listing with upstream's screenshots and changelogs; `codecov.yml` and the codecov badge point at upstream's account; the about screen (`more/` package, `aboutlibraries` config) may link to upstream's site, Weblate and donation pages. LeNews has none of these relationships and must not pretend to.

Delete: `FUNDING.yml`, `codecov.yml`, `fastlane/`, `images/*-badge.png`, `images/readrops_logo.png`, the Weblate link and badge, every donation link, every link to `readrops.com`, the upstream GitHub org, or upstream's Play/F-Droid pages. Retarget what must exist to `https://github.com/jmnicolas90/LeNews`: GitHub issues become the only contact channel. Substitute **no** email address anywhere. Check the about screen at runtime, not just by grep.

Attribution stays untouched: `LICENSE`, GPL headers, the fork-origin sentence that ticket 08 writes, the third-party licence list generated by `aboutlibraries` (it is the libraries' attribution, not upstream's contact info).

**Done when** the gate is green (G1 included), `grep -ri "paypal\|weblate\|codecov\|f-droid\|play.google\|readrops.com\|readrops/Readrops"` returns only `CHANGELOG.md` and the code-review file, and the about screen shows no upstream link.
## Answer (2026-09-06)

Every upstream contact, funding and store surface is gone. Nothing in the tree
now claims a relationship LeNews does not have. The gate is green G0 to G7.

### Deleted outright

- `.github/FUNDING.yml` — one line, upstream's PayPal.
- `codecov.yml` — upstream's codecov account. Nothing referenced it: the gate
  and `.github/workflows/ci.yml` never uploaded coverage (ticket 03 wrote CI
  without codecov).
- `fastlane/` — 31 files: upstream's Play/F-Droid listing, the two descriptions,
  20 changelogs, the icon, the feature and promo graphics and six screenshots.
- `images/` — the whole directory, its only four files being
  `google-play-badge.png`, `fdroid-badge.png`, `paypal-badge.png` and
  `readrops_logo.png`. Nothing in the app ever read them; only `README.md` did.
- `app/src/main/java/app/lenews/more/DonationDialog.kt` and its entry in
  `MoreTab`, with the four imports the entry's `showDonationDialog` state needed
  (`getValue`, `setValue`, `remember`, `mutableStateOf`).
- `app/src/main/res/drawable/ic_donation.xml` — the dialog's and the menu
  entry's icon, used by nothing else.
- Nine strings from `app/src/main/res/values/strings.xml`: `make_donation`,
  `donation_text`, `paypal`, `paypal_url`, `bitcoin_address`,
  `litecoin_address`, `bitcoin_copy_address`, `litecoin_copy_address`, and
  `app_changelog_url` — the last a duplicate of `changelog_url` that no code
  referenced (lint had it as `UnusedResources`).
- Two lines from `.gitignore`, `fastlane/Appfile` and `fastlane/Fastfile`, plus
  the `Gemfile` line beside them. They ignored files this repo never had, for a
  tool it no longer carries.

### Orphaned translations removed

Two groups, 46 strings across nine locale files, all of them translations of
English strings that no longer exist:

- The four translatable donation strings this ticket deleted (`make_donation`,
  `donation_text`, `bitcoin_copy_address`, `litecoin_copy_address`) — 35 lines
  in `values-de`, `-es`, `-fr`, `-ja`, `-nl`, `-pt-rBR`, `-ta`, `-zh-rCN`,
  `-zh-rTW`.
- `greader_warning` and `fever_warning` — 11 lines in `values-es`, `-fr`,
  `-pt-rBR`, `-ta`, `-zh-rCN`, `-zh-rTW`. Ticket 04 deleted their English
  originals and ticket 05 left the translations behind for the locales call.
  They are this ticket's after all: every one of them ends by telling the reader
  to report the problem "to the Readrops GitHub repository", which is an upstream
  contact point shipped inside the APK. `app/src/`, resources included, now
  matches `readrops` nowhere at all.

The wider `ExtraTranslation` debt — 135 further locale strings with no English
original, inherited from ticket 04's service deletion — was **not** swept. That
is the locales product call's, not this ticket's.

### The issue templates: rewritten, not deleted

`.github/ISSUE_TEMPLATE/bug_report.md` and `feature_request.md` are kept and
rewritten. GitHub issues are now the only contact channel LeNews has, so a
template that asks the right questions up front is worth more than no template.
The bug report asks for the FreshRSS version, the LeNews version, the Android
version, the device and the steps, and offers the crash screen's stack trace as
a checkbox; the old "Account type" and "Store" fields are gone (one service, no
store) and so is the upstream phrasing. The feature request is the same shape,
shorter, with no link anywhere in either file.

### `README.md`

Stripped only, as the ticket asks; ticket 08 writes the real one. Gone: the
upstream logo, the CI, codecov and Weblate badges, the Play Store and F-Droid
badges and links, the multi-service feature list, the six screenshots and the
whole donation section with its PayPal link and the two crypto addresses. What

corrected `local.properties` snippet (upstream's example used
`debug.nextcloud_news.*`, which ticket 04 deleted; the keys the build actually
reads are `debug.freshrss.url` / `.login` / `.password`).

against a throwaway HTTP server on the host (`10.0.2.2:8099`) answering
`accounts/ClientLogin`, `token`, `user-info` and the four sync endpoints with
empty results — cleartext to the emulator's host alias, no real server touched,
the script deleted afterwards and the app uninstalled. `build/about-screen.png`:

- the LN mark, **LeNews**, **v0.1.0 (1)**, "App released under the GPLv3 licence";
- three icon buttons — GitHub, changelog, bug report — and nothing else on that row;
- **Settings**, **Open source libraries**, **Debug**. No "Make a donation" entry.

Each of the three icons was tapped and the URL read out of the browser that
opened: `https://github.com/jmnicolas90/LeNews`,
`https://github.com/jmnicolas90/LeNews/blob/main/CHANGELOG.md`,
`https://github.com/jmnicolas90/LeNews/issues`. All three answered 404 on the

happened, and all three answer 200 now** (checked 2026-09-06, after the
repository rename and the working-directory rename; see ticket 05). The `aboutlibraries` licence list is
untouched and still reachable from "Open source libraries".
